# Temitope — Cybersecurity & Technology Portfolio

A personal portfolio built with Next.js, React, and TypeScript.

The site showcases my work across cybersecurity, web development, and web design, with a focus on building useful digital experiences with security in mind.

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- React Icons

## Security

Security is considered throughout the project, including:

- Content Security Policy
- X-Content-Type-Options
- Referrer-Policy
- X-Frame-Options
- Permissions-Policy
- Dependency auditing
- Git-based secret protection

## Features

- Responsive design
- Mobile navigation
- Project showcase
- Skills section
- Contact section
- Social links
- Custom SVG logo
- Optimized project images
